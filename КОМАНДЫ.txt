---- Остановка всех сервисов и фронтенда:

ДОП КОМАНДЫ:


---- Поднятие только БД PostgreSQL (для локального запуска микросервисов из IDE):
docker compose up -d postgres

---- Запуск всех unit & integration тестов во всех модулях:
./mvnw test

---- Запуск тестов со сбором JaCoCo покрытия (сводный отчет в target/coverage-report/):
./run-tests-with-coverage.sh

---- Быстрое открытие дашборда покрытия в браузере:
./run-tests-with-coverage.sh --open

---- Запуск тестов прямо в IntelliJ IDEA (вверху в выпадающем списке Run Configurations):
1. Выбрать "All Tests with Coverage" -> нажать Run with Coverage (зеленый щиток)
2. Или выбрать "Maven: Сборка всех тестов и отчетов JaCoCo" -> нажать Run

---- Тест распределенной транзакции явки:
export JAVA_HOME="/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home"
./mvnw test -Dtest=AttendanceTransactionalTest
